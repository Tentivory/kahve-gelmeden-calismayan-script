# Kahve Gelmeden Çalışmayan Script

## Resmi Açıklama (Ciddiye Alınız, Yoksa Çalışmaz)

Bu repository, insanlık tarihinin en önemli sorununa çözüm üretmek amacıyla oluşturulmuştur: **Kahve gelmeden kod yazmak mümkün müdür?**

Cevap: **Hayır.**

Bu script, bilimsel olarak kanıtlanmış (kaynak: benim hayal gücüm) bir gerçeği yansıtır. Kahve olmadan hiçbir şey çalışmaz. Özellikle de bu script.

### Nasıl Çalışır?

1. Script'i çalıştırın: `python3 kahve_bekleyen.py`
2. Dramatik bekleyişi izleyin.
3. "kahve" yazana kadar bekleyin.
4. Kahve yazınca merhaba dünya diyor. Mucize!

### Neden Bu Kadar Ciddi?

Çünkü kahve ciddi bir meseledir. Ciddiye almazsanız, program da sizi ciddiye almaz. Bu bir simbiyotik ilişkidir.

### Katkıda Bulunma

Kahve gönderin. Pull request kabul edilir ama sadece kahve eşliğinde.
